# VRC++ 0.9.0-beta.3 发布说明

发布日期：2026-08-16  
定位：特别关心好友全景档案与关系网完整扫描版本。

## 本版变化

- 新增独立“特别关心”页面，可固定一位好友并集中查看公开资料与本机证据；
- 展示近 30 天完整本机日志、世界轨迹、上下线、位置变化和同场记录；
- 新增公开、好友、好友+、邀请+、群组和私人实例类型记录；
- 当前可见位置能够区分“处于私人实例”和“可见信息显示其持有私人实例”；
- 新增同一时段本机日志人物线索，帮助回看可能的同场活动；
- 关系网扫描开始保存首次基线、新观察到关系和未再次观察到关系；
- 关系网默认扫描最多 100 位好友；不足 100 位时默认扫描全部；
- 新增“一键扫描全部好友”按钮和完整关系体验提示；
- 好友聚焦时间线从 20 条扩展到当前保留期内最多 500 条。

## 证据与隐私边界

- “新观察到关系”只说明两次共同好友扫描之间结果变化，不能证明具体加好友时间；
- 同场人物只说明相邻时间的本机游戏日志中出现过，不能证明私聊或直接互动；
- 私人实例可能隐藏世界和拥有者，页面不会绕过 VRChat 的可见性限制；
- 原始实例 nonce 和私密标识不会写入活动历史，只保存脱敏后的世界 ID 与实例类型；
- 所有关系变化、日志和特别关心设置只保存在当前电脑。

## 当前边界

- 当前安装程序仍未配置可信 Authenticode 证书，可手动下载安装；
- 应用内自动覆盖升级会按安全策略拒绝未签名安装包；
- 真实账号长期 Pipeline、全好友扫描限流和真实好友数据展示仍需人工验收。

当前安装程序：`VRC++-Setup-0.9.0-beta.3.exe`
