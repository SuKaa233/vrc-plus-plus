# VRC++ 0.9.0-beta.22

定位：可解释的社交记忆、大规模关系网基础优化与特别关心 2.0。

## 新功能

- 今日简报增加可信度和可核对的证据摘要，继续限制为最多 5 条高价值信息；
- 好友动向增加 1/7/30 天好友回放、完整交汇变化列表和共同移动链；
- 覆盖度地图扩展为全量好友，展示观察天数、事件来源、世界证据和 0-100 覆盖评分；
- 特别关心增加上线稳定时长、世界变化、位置变为可加入、免打扰时段、即时或每日汇总邮件；
- 增加投递健康面板，区分成功、失败、等待汇总和免打扰拦截。

## 性能与交互

- 大规模关系图的力导向布局移入 Web Worker；
- 大图连线改由 Canvas 分层绘制，头像节点保持可交互；
- 根据缩放级别减少低价值 DOM 节点，放大或锁定后自动恢复细节；
- 增加实时 FPS 与长任务计数，并加入 500 节点、5000 条边回归数据；
- 单击节点只锁定关系，双击才打开好友档案，两个操作不再互相抢占。

## 边界说明

- 关系变化表示本机两个观察窗口之间的差异，不等于确认加好友或删除好友；
- 共同移动只表示多人在相近时段出现相同世界变化，不推断谁带领了谁；
- 免打扰、汇总队列、SMTP 授权码和投递记录均保存在本机，授权码继续由 Windows 加密保护。
