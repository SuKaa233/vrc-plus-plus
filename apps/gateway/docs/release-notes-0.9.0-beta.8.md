# VRC++ 0.9.0-beta.8 发布说明

发布日期：2026-08-18  
定位：好友上下线提醒、邮件推送与高 DPI 阅读体验。

## 本版变化

- 新增“上线提醒”，可搜索并关注任意好友；
- 每位好友可分别选择上线、下线、Windows 托盘和邮件提醒；
- 基于 Pipeline 状态变化触发，不会按关注人数高频轮询 REST API；
- 首次关注会写入当前在线基线，应用启动或 Pipeline 重连不会集中误报；
- 新增 SMTP TLS / STARTTLS 配置、测试邮件和最近投递结果；
- SMTP 授权码通过 Windows DPAPI 加密保存，不读取浏览器 Cookie 或邮箱密码；
- 移除与 Windows DPI 叠加的整页 CSS `zoom`，字体大小独立为 90%–125%；
- 收敛小字号并隐藏重复的页面说明，降低长时间阅读疲劳；
- 延续 beta.7 的大关系网渐进头像加载、节点锁定和连线聚焦优化。

## 当前边界

- 监测依赖 VRC++ 在本机运行且 Pipeline 已连接；关机、休眠或断网期间无法保证事件送达；
- 邮件服务还会受到邮箱服务商 SMTP 策略、授权码和发送频率限制；
- 浏览器中的邮箱登录状态不会被 VRC++ 读取或复用；
- 安装程序仍未配置可信 Authenticode 证书，需要手动确认安装。

当前安装程序：`VRC++-Setup-0.9.0-beta.8.exe`
