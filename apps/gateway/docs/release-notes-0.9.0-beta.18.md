# VRC++ 0.9.0-beta.18

## 复杂关系网重构

- 关系图改为“自己 → 全部共同好友交集 → 目标用户”的分层阅读顺序。
- 全部共同好友均进入关系图和共同好友列表，不再只展示前 18 个图节点或前 36 个列表项。
- 用蓝线表示“你与共同好友”，绿线表示“共同好友与目标”，虚线表示本机同实例观察。
- 单击节点现在只锁定关系并持续高亮，鼠标移开不会消失；双击人物节点才打开档案。
- 大量共同好友时图内独立滚动；超过 60 位时仅为当前聚焦节点加载头像，但所有节点、姓名和相交边仍完整保留。

## 最近相遇全量展示

- 移除最近相遇最多 24 位、搜索下拉最多 8 位的双重限制。
- 所有本机记录到的圈外人物按最后相遇时间排序并完整展示。
- 下拉框和列表使用独立滚动与离屏延迟渲染，避免全量展示重新拖慢页面。

## 罗盘恢复可用

- 修复罗盘只接受“在线好友公开可加入位置”导致页面长期为空的问题。
- 建议优先级调整为：实时好友路线、收藏/历史世界、热门公开世界。
- 非实时建议明确标注“世界建议，不代表好友正在其中”，不拿缓存位置冒充实时位置。
- 新增在线好友、公开可加入位置、已知世界、本机事件和关系连线的数据覆盖面板。
- 新增“刷新罗盘”，会重新读取好友、世界、收藏、本机历史和本地关系网。
- 本机问答新增“今晚去哪”，即使没有好友公开位置也能返回可执行建议。
