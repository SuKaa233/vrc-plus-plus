# VRC++ 0.9.0-beta.1 发布候选说明

发布日期候选：2026-08-15  
定位：首个小范围公开测试版，不是 1.0 稳定版。

## 本版可用能力

- 本机加密登录会话、VRChat 2FA 与国内网络/代理配置；
- 好友状态、详情、共同好友、朋友圈关系网和好友动向聚合；
- 世界搜索、公共实例、VRChat 收藏、群组、日历与头像收藏；
- 本机活动历史、世界护照、社交潮汐、今晚罗盘和重逢雷达；
- 通知处理、逐人邀请、单人好友请求和单人 Boop；
- 深浅主题、中英文外壳、界面比例、托盘、签名脚本与双源更新底座。

## 本轮发布收口

- 版本统一为 `0.9.0-beta.1`；
- 产品名统一为 `VRC++`，使用用户提供图片替换应用内 Logo、浏览器标签图标和 Apple Touch 图标；
- 登录页移除实施蓝图入口，正式运行时不再提供开发文档路由；
- 更新检查改为语义化版本比较，防止旧版本或同版本被误判为更新；
- 邀请请求头/请求体和 403 提示已修复；新增好友 Boop。

## 已知边界

- VRChat 接口并非官方稳定开发者契约，未来字段和端点可能变化；
- 私人位置、隐身状态和应用未运行时的活动不可见；
- 中英文切换尚未覆盖所有业务详情组件；
- 正式代码签名证书、国内对象存储和 GitHub Release 双源尚未配置；
- 邀请和 Boop 已通过模拟上游与本机网关测试，但候选包尚未执行真实好友写操作验收。

## 发布前人工验收

- [ ] 在干净 Windows 10 与 Windows 11 各安装一次；
- [ ] 登录、2FA、退出、重启恢复各验证一次；
- [ ] 征得好友同意后，各发送一次邀请和 Boop；
- [ ] 验证托盘打开、隐藏、退出和卸载保留用户数据；
- [ ] 配置可信证书并检查 Authenticode；
- [ ] 上传签名安装程序到正式下载源，验证下载、覆盖升级和失败回滚；
- [ ] 确认安装程序、下载页和“关于”页面版本号一致。

当前候选安装程序：`VRC++-Setup-0.9.0-beta.1.exe`
