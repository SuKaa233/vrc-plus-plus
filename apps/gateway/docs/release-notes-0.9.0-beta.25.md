# VRC++ 0.9.0-beta.25

定位：从 VRChat 会话守护延伸到本机相片与设备管理。

## VRChat 相片库

- 自动发现 Windows 图片目录中的 VRChat 相机照片，按日期分组并支持文件名搜索；
- 使用按需生成的本机缩略图缓存，大量高清照片不再直接挤占页面内存；
- 展示分辨率、画面比例、像素、格式、大小、拍摄时间、修改时间、完整路径、SHA-256 和可读取的 PNG 文本信息；
- 支持大图查看、左右旋转、重命名和打开所在位置；
- 旋转前保留原图备份，删除先移入 VRC++ 回收区，降低误操作风险。

## 头显与运行环境

- 从 Windows 当前设备中识别 Meta Quest、PICO、Valve Index、HTC VIVE、Windows Mixed Reality、Varjo、Bigscreen Beyond 等设备；
- 合并同一头显关联的音频与串流接口，避免重复显示；
- 展示 SteamVR、Meta Quest Link、PICO Connect 与 Virtual Desktop 的安装和运行状态。

## 守护续玩

- 新增满房空位提醒，每分钟低频检查并通过托盘通知；
- 新增好友去向追踪，短时核对刚才同房好友当前可见的位置；
- 空位和好友新去向均可直接通过 VRChat 官方启动链接打开。

## 界面文案

- 移除“已交付”“下一阶段”等研发汇报口径；
- 将 Pipeline、接口确认、扫描候选等内部术语替换为普通用户可理解的表达。

## 边界说明

- 相片与设备信息只在本机读取和处理，不上传服务器；
- 头显“已连接”来自 Windows 当前设备状态，“已安装”和“正在运行”单独展示；
- 安装包尚未获得受信任 Authenticode 证书签名，Windows 可能显示未知发布者提示。
