# VRC++ 0.9.0-beta.9 发布说明

发布日期：2026-08-18  
定位：邮件推送安全加固。

## 本版变化

- 邮件收件地址必须与发件地址一致，避免被用作公共邮件转发器；
- 单个好友十分钟最多发送一封邮件；
- 全局每小时最多发送二十封邮件；
- 邮件总开关和每位好友的邮件开关仍默认关闭；
- SMTP 授权码继续通过 Windows DPAPI 加密，仅保存在当前 Windows 用户的数据目录。

## 安全边界

- 不在源码、安装包、更新清单或 Git 历史中内置邮箱授权码；
- 不读取或复用浏览器邮箱登录状态；
- 只有 VRC++ 正在运行且 Pipeline 在线时才能监测状态变化。

当前安装程序：`VRC++-Setup-0.9.0-beta.9.exe`
