# VRC++ 0.9.0-beta.5 发布说明

发布日期：2026-08-16  
定位：特别关心好友搜索与证据化社交参考推测。

## 本版变化

- “特别关心”页面新增即时好友搜索，不再需要逐项翻找；
- 支持按好友昵称、`usr_` 用户 ID、状态说明和平台搜索；
- 搜索结果优先显示精确名称匹配和在线好友，并显示头像与状态；
- 新增关系网角色参考，比较该好友连接数在当前关系网中的位置；
- 新增关系变化趋势，汇总新观察和未再次观察到的关系；
- 新增实例偏好、世界回访倾向和常见活跃时段参考；
- 新增同场人物与关系圈重合度、最近一周活动集中度参考；
- 每条参考推测都展示数据证据和较高/中等/较低置信度；
- 延续 beta.4 的安装目录选择和自动创建快捷方式修复。

## 证据边界

- 所有结论仅基于当前电脑已保存的关系扫描、Pipeline 和游戏日志；
- 关系变化不能证明具体添加或删除好友行为；
- 同场日志不能证明私聊或直接互动；
- 数据覆盖不足时降低置信度或不生成对应结论；
- 页面不会推断年龄、性别、身份、现实关系等敏感属性。

## 当前边界

- 当前安装程序仍未配置可信 Authenticode 证书，可手动下载安装；
- 应用内自动覆盖升级会按安全策略拒绝未签名安装包；
- 搜索交互、推测内容和安装体验仍需真实好友数据与干净 Windows 人工验收。

当前安装程序：`VRC++-Setup-0.9.0-beta.5.exe`
