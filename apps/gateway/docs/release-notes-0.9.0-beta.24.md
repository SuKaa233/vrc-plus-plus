# VRC++ 0.9.0-beta.24

定位：明确、可预期的 Windows 覆盖升级安装体验。

## 安装与升级

- 安装前同时检查当前用户和系统范围内已有的 VRC++ 安装记录；
- 检测到旧版本后，明确显示旧版本、新版本和原安装目录；
- 已安装用户执行原位覆盖升级，不再要求先卸载，也不会引导到另一个目录；
- 覆盖升级沿用原安装目录并替换程序文件；
- 好友记录、登录会话、特别关心、邮件配置和守护记录保存在独立本机数据目录，升级时继续保留；
- 首次安装仍然显示安装路径选择，并继续创建桌面快捷方式。

## 功能内容

- 包含 beta.23 的 VRChat 守护与续玩、异常退出救援和完整本机会话现场；
- 包含特别关心 2.0、好友动向回放和大型关系网性能优化。

## 边界说明

- 本版本选择覆盖升级而不是卸载重装，避免破坏用户设置和安装选择；
- 安装包尚未获得受信任 Authenticode 证书签名，Windows 可能显示未知发布者提示。
