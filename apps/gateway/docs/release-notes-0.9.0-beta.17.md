# VRC++ 0.9.0-beta.17

## 修复陌生人页面右侧被裁切

- 修复控制台双列网格被内容最小宽度撑开、又被全局横向隐藏裁切的问题。
- 陌生人页面、搜索栏、结果卡片和关系区现在按实际内容区宽度自适应。
- 宽度不足时搜索区自动重排，搜索结果与下方信息自动改单列，不再要求用户寻找隐藏横向滚动条。
- 适配 125% 字体缩放和高 DPI 下的按钮文字增长。

## 共同好友成为独立证据源

- 新增“对方好友中可验证的部分”，直接展示共同好友明细、头像、状态、数据来源和读取时间。
- 新增一键刷新共同好友，明确区分实时接口、本地缓存、未共享或接口不可用。
- 共同好友列表可点击继续查看人物档案；超过 36 位时渐进展示，完整结果仍参与推断。
- 明确说明共同好友只是双方好友列表的交集，VRChat 不向当前账号提供对方完整好友列表。

## 多源关系推断

- 新增“共同好友 + 可见群组成员”的双来源交叉印证。
- 新增“共同好友 + 本机同实例日志”的活动交叉印证。
- 新增共同好友当前可见状态分析，但不把在线状态解释为正在与目标互动。
- 关系图会为共同好友补充同实例观察虚线，论证卡同步展示来源、限制和验证步骤。
