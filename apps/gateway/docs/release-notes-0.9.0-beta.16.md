# VRC++ 0.9.0-beta.16

## 最近相遇一键查询

- 搜索框新增“最近相遇”下拉信息框，直接展示最近遇见的非好友。
- 下拉项显示人物名称、本机记录数量和最后相遇时间。
- 点击“一键查询”后直接读取该用户并自动生成档案、关系图与推测，不再停留在搜索结果列表。
- 没有本机记录时明确说明数据如何产生，不要求用户手动导入。

## 可验证的推测论证卡

- 所有关系推测卡现在都可以点击打开完整论证。
- 论证卡明确显示“现有证据支持、部分支持、证据不足或边界条件成立”。
- 展示本次结论使用的数据来源和全部直接证据。
- 单独列出该结论不能证明的内容，避免把相关性解释成真实互动或亲密关系。
- 针对共同好友、公开群组、本机日志和公开资料分别提供进一步验证步骤。
- 明确提醒数据刷新、隐私权限和样本范围改变后结论可能变化。

## 更多关系推测

- 新增混合桥接型、共同好友主导型、公开群组主导型和弱连接型关系结构判断。
- 新增可见圈层集中度分析，计算成员记录是否集中在单一群组。
- 新增重复同实例线索分析，仅在相同实例和 30 分钟时间窗口内匹配。
- 新增账号历史与信任元数据交叉参考，但不将信任等级解释为个人可信度。
- 新增社交可见度分析，综合简介、语言、群组和活动可见性。

## 可读性

- 陌生人页面正文、指标、档案、候选列表和工具栏字号整体提高。
- 推测卡正文提升至 12px，标题提升至 14px。
- 论证弹窗正文为 12–13px，主标题为 21px，更适合高 DPI 和 125% 缩放环境。
