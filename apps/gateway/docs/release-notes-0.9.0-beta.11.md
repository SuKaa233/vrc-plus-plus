# VRC++ 0.9.0-beta.11

## 陌生人查看成为独立模块

- 原“发现”升级为一级“陌生人”模块，集中展示搜索、最近同房、公开群组候选和本地收藏。
- 搜索结果直接显示共同好友、共同群组、代表群组等关系证据，不再把扩展字段全部藏在详情抽屉中。
- 支持以某个用户为起点读取其对当前账号可见的群组，再从允许查看成员的群组中展开圈外候选。
- 候选列表自动排除自己的好友，并可继续打开完整公开资料、收藏到本机或发送好友请求。
- 新增本地陌生人收藏，每个 VRChat 账号独立保存，最多保留 200 位，不上传到 VRC++ 服务。

## 合规与稳定性

- 明确说明 VRChat 不提供任意用户的完整好友列表；共同好友、群组成员和同房记录均标注为线索，不推断真实好友关系。
- 群组成员只访问当前登录账号有权查看的接口，权限不足时显示原因，不尝试绕过隐私设置。
- 单次群组成员展开限制为 100 位，并使用 15 分钟缓存，避免高频请求和大型群组拖慢界面。
- 新增群组成员接口解析、分页边界和前端本机路由测试。
