# VRC++ 0.9.0-beta.6 发布说明

发布日期：2026-08-16  
定位：500+ 好友全量关系网性能优化。

## 本版变化

- 超过 220 个可见节点或 1800 条可见连线时，自动启用“大图流畅模式”；
- 完整关系数据继续用于好友搜索、最短路径、朋友圈、跨圈关键好友和历史变化统计；
- 画布默认绘制确定性的关系骨架与高价值连线，悬停好友时补充其直接关系；
- 页面显示完整关系数与当前绘制数，用户仍可主动切换“显示全部连线”；
- 力导向布局在大图下减少迭代，并限制参与布局计算的代表边数量；
- 节点碰撞检测由全量两两比较改为空间网格邻域比较；
- 大图只优先加载核心、固定、寻路和当前焦点好友头像，不再同时请求和转码数百张图片；
- 修复点击好友后关系聚焦态永久保留、看起来像白色遮罩的问题；点击只保留选中圈，只有短暂悬停才压暗非直连线；
- 在滚轮缩放、空白拖动、离开画布、窗口失焦、页面隐藏和筛选移除节点时统一释放悬停状态；
- 新增 520 个好友、约 1.2 万条输入关系的自动化压力回归。

## 数据与显示边界

- “流畅模式”只减少画布同时绘制的连线和头像，不删除任何已扫描关系；
- 搜索、关系路径和统计始终基于当前筛选范围内的完整关系；
- “显示全部连线”适合排查细节，超大关系网开启前会提示可能降低流畅度；
- 缺少头像时继续显示好友名称首字母，不影响关系数据。

## 当前边界

- 已通过前端类型检查、单元测试和合成大图压力回归；
- 仍需使用用户当前 500+ 好友真实数据复核 WebView2 中的首次打开、连续悬停和缩放手感；
- 当前安装程序仍未配置可信 Authenticode 证书，可手动下载安装；
- 应用内自动覆盖升级会按安全策略拒绝未签名安装包。

当前安装程序：`VRC++-Setup-0.9.0-beta.6.exe`
