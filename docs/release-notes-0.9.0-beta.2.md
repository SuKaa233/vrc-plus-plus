# VRC++ 0.9.0-beta.2 发布候选说明

发布日期候选：2026-08-16  
定位：P1 社交洞察产品主线与安装程序自动更新首个候选版本。

## 本版变化

- 今日首页加入最多 5 条、可回查的本机社交简报；
- 好友档案加入共同会话、共同世界、来源覆盖和 24 小时、7 天、30 天聚焦回放；
- 旅程加入交汇变化、共同移动链和好友覆盖度地图；
- 世界回忆加入首次/最近观测、自然日覆盖和同行好友；
- 关系网保存按账号隔离的 30 天每日快照，以“已观察变化”展示差量；
- 实例页区分可启动、满员、失效和详情受限，并展示当前好友线索；
- 更新发布格式统一为 Windows `Setup.exe`；
- 启动 12 秒后自动检查，之后每 6 小时复查；
- 新版本提示、后台下载、静默覆盖安装和自动重启；
- 支持国内更新源优先、GitHub Releases 备用；
- 更新请求跟随应用的网络与本机代理设置；
- 下载后的安装程序使用 Windows Authenticode 验证；
- 新增更新清单生成脚本和 GitHub Release 发布脚本；
- 发布过程不生成 ZIP，也不生成对外文件校验值。
