# VRC++ 0.9.0-beta.26

## 修复与改进

- 修复全量扫描后关系数据存在、但大图模式一条连线都不显示的问题。大规模关系网现在保留完整统计，并稳定显示经过预算筛选的关键连线。
- 满房空位提醒不再要求手动填写实例 ID。页面会自动汇总当前房间、最近房间和好友公开可见的房间，选择后即可开始蹲守。
- 罗盘进入页面时改为后台更新，不再因逐个补全历史世界信息而长时间停留在“刷新中”。手动刷新仍会给出明确状态。
- 空位提醒会携带正确的世界名称，不再错误复用当前或最近房间名称。

## 说明

- 关系网的“流畅模式”只限制同屏绘制数量，不会丢弃共同好友关系、路径搜索或统计数据。
- 隐藏位置、离线状态以及 VRChat 未向当前用户公开的信息不会被列入可蹲守房间。
