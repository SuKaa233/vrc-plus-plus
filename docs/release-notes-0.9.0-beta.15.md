# VRC++ 0.9.0-beta.15

## 陌生人模块进入即用

- 进入陌生人模块后立即展示完整关系图和推测能力预览，不再出现不知道如何开始的空白页面。
- 功能预览使用明确标注的示例数据，不冒充真实用户或真实关系。
- 后台自动读取本机活动记录，优先选择最近遇见的非好友并生成真实档案和关系图。
- 若活动记录没有候选，则继续检查通知中的圈外发送者。
- 若仍没有候选，则从当前账号可见的第一个群组中寻找非好友成员。
- 找到真实人物后自动补全公开资料、共同好友、公开群组、群组成员、复杂关系图和多维推测。
- 自动发现失败时保留功能预览，并明确解释缺少哪类真实数据。
- 每个账号最多每 5 分钟自动重试一次，新的同房日志出现后无需导入即可自动切换到真实关系。

## 首屏亮点

- 首屏直接说明三步能力：自动发现圈外人物、生成可锁定关系图、输出带证据的多维推测。
- 自动发现过程显示当前数据来源和进度，让用户知道系统正在做什么。
- 手动搜索仍作为补充入口保留，但不再是体验陌生人模块的前置条件。
