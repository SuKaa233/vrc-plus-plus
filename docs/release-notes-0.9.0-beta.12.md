# VRC++ 0.9.0-beta.12

## 陌生人全景档案

- “陌生人查看”新增页面内全景档案，不再依赖详情抽屉查看上一版补充的字段。
- 身份区展示在线状态、信任等级、平台、代词、用户 ID、VRC+、好友关系和经济系统创作者身份。
- 资料区展示状态描述、完整简介、公开链接、共同好友、共同群组、语言和账号加入日期。
- 活动区区分当前活动、位置受限、世界、实例和切换世界目标，不将空位置误判为私人房。
- 时间区展示最后活动、最后登录、最后移动端活动及活动可见性。
- 身份权限区展示开发者类型、头像复制权限、年龄验证返回状态和资料来源。
- 装饰区展示主题、图标框、铭牌效果、资料效果、横幅与背景类型。
- 代表群组、公开徽章和 VRChat 原始标签直接显示在档案底部。

## 关系补全体验

- 点击关系线索后自动读取完整公开档案。
- 自动优先展开代表群组；没有代表群组时展开第一个当前账号可见的群组。
- 档案读取、群组读取和成员读取相互容错；群组成员无权限时仍保留已经读取到的人物资料。
- 所有缺失值明确显示“未公开”“未读取”或“受限”，避免把接口空值解释成事实。
