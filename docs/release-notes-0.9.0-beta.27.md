# VRC++ 0.9.0-beta.27

## 修复

- 修复相片页自动检测头显时弹出 PowerShell/CMD 窗口的问题。相关 Windows 子进程现在以无控制台窗口方式运行。
- 修复关系网拥有完整扫描数据却整块空白的问题。220 个以内的节点直接可靠布局，不再因边数较多误入 Worker-only 路径。
- 超过 220 个节点时先立即显示轻量关系布局，再由后台 Worker 优化；即使 Worker 无法启动或响应，关系图也不会再次空白。

## 验证

- 已增加 166 节点、2494 条关系的回归条件测试。
- 已增加 Windows 硬件检测命令无窗口属性测试。
