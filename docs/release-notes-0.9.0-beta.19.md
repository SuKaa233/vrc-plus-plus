# VRC++ 0.9.0-beta.19

## 更新提醒与下载

- 客户端启动后会自动检查新版本，此后每 10 分钟再次检查。
- 每个新版本只发送一次 Windows 托盘提醒，避免重复打扰。
- 右下角更新卡片会显示当前版本、最新版本和本次更新内容。
- 更新按钮改为直接打开 GitHub 安装包下载页，不再因安装包尚未签名而卡在内置签名验证。

## 发布可靠性

- 发布脚本会把最新清单同步到 Beta 滚动更新通道。
- 发布结束后会在线校验更新通道版本，避免老客户端收不到新版本。
- 更新清单自动读取本版发布说明，让客户端能看到实际更新内容。

> 当前安装包尚未配置受信任的代码签名证书。Windows 可能仍显示“未知发布者”，请仅从本仓库的 GitHub Releases 页面下载并核对发布来源。
