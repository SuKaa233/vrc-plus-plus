# VRC++ 0.9.0-beta.4 发布说明

发布日期：2026-08-16  
定位：修正安装目录和快捷方式体验。

## 本版变化

- 手动启动安装程序时始终显示安装目录选择页；
- 检测到旧版本时默认沿用原安装目录，用户仍可修改；
- 首次安装和覆盖安装都会创建桌面快捷方式；
- 开始菜单快捷方式继续自动创建；
- 程序内自动更新继续以静默方式覆盖原目录，不弹出安装向导；
- 自动更新完成后也会补建缺失的桌面和开始菜单快捷方式。

## 当前边界

- 当前安装程序仍未配置可信 Authenticode 证书，可手动下载安装；
- 应用内自动覆盖升级会按安全策略拒绝未签名安装包；
- 安装路径页面、快捷方式和静默覆盖仍需在干净 Windows 与已安装 beta.3 的环境分别人工验收。

当前安装程序：`VRC++-Setup-0.9.0-beta.4.exe`
