# VRC++ 0.9.0-beta.7 发布说明

发布日期：2026-08-16  
定位：大图头像渐进补齐与好友关系锁定。

## 本版变化

- 修复 beta.6 大图模式只加载约 72 个重点头像、其余好友永久显示首字母的问题；
- 首批优先加载 72 个核心头像，之后每 500ms 开放 16 个，最终加载全部具有可用图片的好友；
- 当前悬停、固定和寻路节点不受批次限制，会优先显示头像；
- 继续使用本机图片代理直接加载，不恢复逐张 Canvas 转码；
- 点击好友会明确锁定该好友及其直接关系，鼠标移开后连线仍然保留；
- 悬停其他好友时临时预览，移开后自动回到已经锁定的好友；
- 画布左上角显示锁定对象和“解除”按钮，点击空白处或按 Esc 也可解除；
- 大图连线抽稀、空间网格碰撞和聚焦态异常释放等 beta.6 优化继续保留。

## 当前边界

- 500 个好友约需二十秒进入全部头像加载队列，实际完成时间还取决于本机缓存与网络；
- 图片源不可用或代理返回失败时仍显示名称首字母；
- 已通过前端类型检查、自动化测试和生产构建，仍需用当前真实 500+ 好友数据复核渐进加载速度；
- 当前安装程序仍未配置可信 Authenticode 证书，需要手动下载安装。

当前安装程序：`VRC++-Setup-0.9.0-beta.7.exe`
