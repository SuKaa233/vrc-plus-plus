# VRC++ 0.9.0-beta.23

定位：VRChat 守护与续玩、特别关心 2.0，以及大型关系网稳定性更新。

## VRChat 守护与续玩

- 新增独立“守护续玩”模块，自动监听本机 VRChat 日志和进程状态；
- 识别正常关闭与疑似异常退出，崩溃后通过托盘和应用内救援条提示；
- 保存最后世界、完整实例地址、区域、访问类型、房主或群组标识，以及退出前仍在房间中的玩家；
- 支持通过 VRChat 官方启动链接返回最近实例，受限实例仍遵循 VRChat 实际访问权限；
- 网关重启后可以恢复尚未结算的本机会话快照；完整状态使用 Windows DPAPI 加密保存在本机。

## 特别关心 2.0

- 增加上线稳定时长、世界变化、位置变为可加入和免打扰时段；
- 支持即时邮件与每日汇总，增加投递健康和失败原因；
- SMTP 授权码继续使用 Windows 加密存储，不写入仓库或明文配置。

## 关系网与交互

- 大规模关系图布局移入 Web Worker，Canvas 分层绘制连线；
- 增加 500 节点、5000 连线回归数据和运行时性能观测；
- 单击锁定关系，双击打开档案，修复两种操作相互抢占；
- 好友动向增加 1/7/30 天回放、交汇变化、共同移动链和覆盖度说明。

## 边界说明

- 守护信息来自用户本机 VRChat 日志，不上传 VRC++ 服务器；
- “返回实例”不绕过房间权限、容量限制或已失效实例；
- 本版本安装包未获得受信任 Authenticode 证书签名，Windows 可能显示未知发布者提示。
