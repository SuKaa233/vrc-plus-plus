# VRC++ 0.9.0-beta.20

## 本版摘要

- 修复锁定图标覆盖画布和人物节点双击无法打开档案的问题。
- 共同好友改为清晰的单一交集通道，并逐条展示关系类型和证据性质。
- 罗盘删除“问问本机记录”，新增汇合、重逢、探索三套行动策略。
- 新增时间预算行动草案、实时好友实例雷达、首选路线和自动候补。

## 关系图修复

1. 检查器加入明确的“打开完整档案”按钮。
2. 每个人的“你的好友”和“对方的好友”关系分色呈现。
3. 支持 Esc 解锁、Enter 打开档案和空格锁定。

## 罗盘行动台

1. 可选择 30/60/120 分钟预算并自动生成行动顺序。
2. 实时好友位置优先于历史建议；探索模式按收藏、历史和公开热度重新排序。
3. 私人房和隐藏位置不会被包装成可加入路线，历史世界也不会声称有好友在场。

## 体验与验证

1. 针对 125% DPI 检查了关系图和罗盘的排版、溢出与按钮可见性。
2. 新增关系布局和罗盘策略测试，前端测试总数增至 50 项。
