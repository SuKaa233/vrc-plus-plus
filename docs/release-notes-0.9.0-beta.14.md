# VRC++ 0.9.0-beta.14

## 陌生人复杂关系图

- 新增以“自己”和目标陌生人为核心的可视化关系图。
- 图中分层展示自己、目标、共同好友、公开群组和圈外群组候选。
- 共同好友同时连接自己和目标，形成可验证的社交桥梁路径。
- 目标公开群组连接可见成员；同一人物出现在多个群组时会形成多条圈层连线。
- 本机日志在同一实例、30 分钟窗口内观察到两人时，使用虚线展示同房线索。
- 支持悬停预览、点击锁定、一跳关系高亮、节点详情、缩放、重置和隐藏群组候选。
- 点击人物节点可以继续打开其完整公开档案。
- 为保证大型关系数据下的流畅度，图中最多显示 18 位共同好友、6 个群组和 30 位候选，并提示省略节点数量。

## 多维关系推测

- 新增共同好友路径、公开圈层重叠、跨群桥接人物、本机活动证据、资料开放度和接触路径分析。
- 每项推测分别展示可信度、结论、直接证据和适用边界。
- 推测只分析可解释的关系路径，不判断亲疏、敌友、恋爱关系或现实身份。
- 明确区分接口确认关系、本机观察线索和覆盖不足，不将群组成员自动推断为好友。

## 数据补全

- 查看目标关系线索时同步读取共同好友明细，用于构建“自己 → 共同好友 → 目标”的真实路径。
- 新增关系图构建与推测逻辑测试，覆盖候选去重、多群连线、共同好友路径和边界提醒。
