# VRC++ 0.9.0-beta.13

## 陌生人关系雷达

- 新增“一键扫描可见群组”，主动触发后依次读取最多 5 个当前账号有权限查看的群组。
- 每个群组最多读取 100 位成员，并复用 15 分钟本地缓存，控制请求频率和页面负载。
- 自动合并同一人物在不同群组中的重复记录，不再需要逐个群组来回翻找。
- 候选人按照共同出现的公开群组数量优先排序，并列出具体来源群组。
- 新增候选人即时搜索，可按显示名称或用户 ID 过滤关系雷达结果。
- 新增扫描进度、完成汇总、未扫描群组数量和不可见群组提示。
- 单独打开某个群组时，成员结果会继续合并进当前关系雷达，不覆盖已经发现的候选人。

## 边界说明

- “共同公开群组”只代表公开关系线索，不等同于好友关系或现实社交关系。
- 扫描只访问当前登录账号被允许查看的群组成员接口，不尝试绕过成员可见性。
