# VRC++ 0.9.0-beta.10 发布说明

发布日期：2026-08-18  
定位：离线好友完整字段与陌生人物资料。

## 本版变化

- 好友列表保留最后活动、最后登录、最后移动端活动、简介、资料链接和完整头像字段；
- 离线好友列表增加最近活动提示和“最近活动”排序；
- 搜索范围扩展到简介、状态说明和最后平台；
- 支持直接输入完整 `usr_` 用户 ID 查看陌生人；
- 人物详情按需合并基础用户资料、公开资料、当前账号可见活动资料和共同关系统计；
- 新增语言、代表群组、VRChat+、创作者状态、徽章、共同好友/群组数量和资料来源；
- 用户详情缓存五分钟，避免重复打开资料时产生连续接口请求；
- 位置为空时显示“位置受限”或“活动信息受限”，不再直接误判为私人实例或确定离线。

## 数据边界

- 隐身、离线和权限受限只能按 VRChat 返回值展示，VRC++ 不绕过隐私设置；
- 共同关系可能因对方关闭分享而不可用；
- 新版资料接口不可用时会自动保留基础用户资料，不影响打开人物档案。

当前安装程序：`VRC++-Setup-0.9.0-beta.10.exe`
